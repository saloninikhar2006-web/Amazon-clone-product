# Amazon-clone-product

This project is a static clone of the Amazon homepage built using HTML,CSS and Javascript.
The goal of this project was to practice front-end web development by recreating the layout and design of a real world e-commerce website.

* Features
  1. Navigation bar similar to Amazon
  2. Structured layout using HTML
  3. Styling using CSS
  4. Responsive page structure
 
 * Technologies used
   
  1. HTML
  2. CSS
  3. Javascript

 * Purpose

   This project was developed to strengthen understanding of web page structure,styling and layout design while building a real-world inspired interface.
